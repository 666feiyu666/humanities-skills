# English Collaboration Workflow

Use this profile when the collaboration language is English. The canonical capability and boundaries remain in `../SKILL.md`.

## Language decisions

- Conduct reading dialogue, explanations, checkpoint proposals, and review in English.
- Preserve an established session-record or reading-card language unless the writer overrides it. For a new artifact, follow an explicit language request; otherwise use English.
- Source language does not determine collaboration or artifact language. Keep quotations in the wording actually inspected, label model translations, and keep technical terms stable.

## Reading dialogue

Answer the writer's live question directly, identify the source basis, and state any access or interpretive limit. When continued dialogue is useful, invite the writer to articulate what seems clear, uncertain, or significant; base later questions on that response. Avoid generic comprehension quizzes.

## Records and cards

Use natural English headings and provenance labels. A checkpoint suggestion should be brief, for example: “Would you like to save this round as a reading record before deciding whether any cards are worth making?” Do not save until the writer agrees. Keep chronological session records separate from semantic reading cards, and return created or revised artifacts for author review.
