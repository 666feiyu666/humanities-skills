# Web-assisted reading

## Purpose

Use the web to support serious reading when the original work is absent or incomplete. Produce the strongest defensible reconstruction available without pretending that secondary coverage equals direct access to the book.

## Declare the mode

Before substantive reconstruction, record:

- the work and edition or translation sought;
- whether the original is absent or only partly visible;
- the question being investigated;
- the current mode: `partial_source` or `web_reconstruction`.

Update the mode if better material becomes available.

Before treating the original as absent, check the user-supplied and project-local materials in scope. When the writer identifies the work as part of their Zotero library, use the Zotero source workflow before beginning web reconstruction. Do not search the writer's Zotero library speculatively when they have not placed it in scope.

## Search in layers

Prefer sources in this order, while matching them to the claim:

1. **Direct source material**: lawful previews, author-posted excerpts, publisher excerpts, tables of contents, indexes, and accessible passages from the work.
2. **Authorial context**: the author's articles, lectures, interviews, later reflections, or archival descriptions that directly illuminate the work.
3. **Scholarly secondary work**: peer-reviewed reviews, journal articles, academic books, dissertations, and authoritative reference works.
4. **Reliable orientation**: library catalogs, university course materials, reputable essays, and serious public reviews.
5. **Discovery only**: retailer copy, search snippets, unsourced summaries, forum posts, and AI-generated pages.

Use discovery-only material to find better sources, not as final evidence for a substantive claim. A library catalog can establish bibliographic facts but usually cannot establish the book's argument.

## Build an evidence ledger

For every material source likely to enter a note, record:

| Field | Meaning |
|---|---|
| Title and author | Identify the page or document |
| URL or stable identifier | Allow return to the material |
| Source role | direct text, authorial context, scholarly secondary, orientation |
| Visible coverage | exact pages, chapter, excerpt, abstract, review, or metadata only |
| Supported claim | State what this source actually establishes |
| Access date | Record when the web material was checked |
| Limits | Paywall, snippet only, missing pages, translation mismatch, or derivative summary |

Do not count several pages repeating publisher copy as independent corroboration.

## Reconstruct with coverage labels

Use these labels in dialogue and notes:

- `directly visible`: supported by a passage actually inspected;
- `partially visible`: supported by excerpts but whole-work context is missing;
- `secondary reconstruction`: supported by reliable commentary about the work;
- `tentative synthesis`: inferred by comparing sources and not directly attributable to the work;
- `unknown`: not established by available material.

State confidence from the quality, proximity, agreement, and coverage of the evidence—not merely the number of search results.

## Answer questions

Lead with the answer that the evidence supports. Then state:

- whether it comes from the work, an authorial source, or secondary scholarship;
- what part of the work is actually covered;
- any serious disagreement or missing context;
- what cannot yet be concluded.

Do not describe a whole-book architecture from one review. Do not use an exact quotation unless the quoted wording is directly visible in a checkable source.

## Preserve legal and textual integrity

- Use lawful, accessible materials and do not bypass access controls.
- Do not seek or rely on obviously pirated copies.
- Quote only brief passages needed for analysis; prefer paraphrase for copyrighted works.
- Link to the page that supports the claim, not a search-results page.
- Distinguish translations and never silently combine their wording.

## Create a web-assisted primary note

Use the standard primary-note schema, but make these fields mandatory:

- reading basis;
- actual visible coverage;
- evidence ledger;
- coverage gaps;
- claims that must be checked against the original before publication.

A web-assisted primary note may support later argument mapping and writing after the writer has chosen a direction. It cannot justify wording such as “the author argues on page X” unless the relevant source text and locator were directly inspected.
