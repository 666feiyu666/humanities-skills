# Primary notes

## Function

A primary note condenses a bounded reading event so that the writer can recover what the source says, what the dialogue clarified, and what remains open. It is source-oriented even when it records personal interest. It does not replace the chronological Q&A record and is not an argument map, processed personal essay, or article draft.

Before synthesizing a substantive multi-turn dialogue in a declared local reading project, preserve that dialogue according to [reading-sessions.md](reading-sessions.md). Create the primary note as a separate artifact and link the relevant session record; do not reproduce or silently rewrite the whole exchange.

## Suggested structure

```markdown
# 标题

## 阅读信息

- 书目：
- 版本或译本：
- 来源入口：读者提供 / 项目材料 / Zotero / 网络
- 来源标识：
- 文件格式与提取方式：
- 阅读模式：原书阅读 / 部分原文辅助阅读 / 网络资料重建
- 阅读范围：
- 实际可见范围：
- 位置系统：
- 记录日期：
- 对话记录：

## 本次阅读的重点

## 内容与论证梳理

## 重要概念

## 关键引文

> 引文

- 位置：
- 当地作用：

## 对话中澄清的问题

## 网络资料与证据台账

| 资料 | 角色 | 可见范围 | 支持的判断 | 局限 |
|---|---|---|---|---|

## 我的关注与联想

## 尚未解决或需要核查

## 可交给思考技能的问题
```

Use only sections that carry information. Several short primary notes are preferable to one indefinite running summary.

For direct-source notes, omit the web evidence table when unused. For `partial_source` and `web_reconstruction`, keep the reading mode, actual visible coverage, evidence ledger, and coverage gaps.

For a Zotero-located source, use the bibliographic item key and attachment key as the stable local-library identity when useful. Record filename, content type, link mode, extraction method, and locator limits only when they affect recovery or verification. Do not preserve an absolute Zotero storage path as the durable identifier, and do not imply that attachment discovery establishes textual coverage.

## Provenance

Use compact markers when a statement could later be mistaken for the source:

- `[原文]`
- `[概括]`
- `[二手重建]`
- `[解释]`
- `[我的想法]`
- `[待核查]`

Locators may be pages, ebook locations, chapter and section names, or stable paragraph identifiers. Never fabricate a locator.

When a claim comes from web research, cite the actual page and do not replace its locator with an inferred book page.

## Updating

Append a dated correction or mark the old understanding as superseded when later reading changes it. Preserve the path of interpretation when it matters; a primary note is also a record of how understanding developed.

## Handoff block

End with a small handoff block only when useful:

```markdown
## 交给 thinking-skill 的材料

- 触动点：
- 可继续追问：
- 可用引文：
- 尚需回原书核查：
```

Keep this block source-facing. Do not preselect a central claim or arrange an article on the writer's behalf.
