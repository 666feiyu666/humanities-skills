# Reading Q&A sessions

## Function

A reading-session record preserves how source understanding developed before synthesis. Keep it chronological and minimally edited. It is an original reference for the later primary note, not the note itself and not an argument map or article commentary.

## When to preserve one

In a declared local reading project, create a session record when:

- the dialogue contains multiple substantive source questions;
- the writer asks to save, close, or synthesize the session; or
- a primary note will draw on the dialogue.

Preserve the session before creating the primary note. Do not create a project artifact for a one-off question unless the writer asks. During an ongoing session, append live only when the writer requests it; otherwise save it at the first checkpoint or close.

## Minimal structure

```markdown
# 阅读问答：主题

## 会话信息

- 书目与来源标识：
- 阅读基础与实际可见范围：
- 位置系统与提取限制：
- 会话日期：

## 问答记录

### Q1

**写作者：** 原问题

**Codex：** 当时回答

- 来源依据与位置：
- 状态：原文重建 / 模型解释 / 待核查
- 后续修正：
```

Use only fields that carry information. Preserve the writer's questions verbatim. Preserve Codex's answers verbatim when practical; if a response must be shortened, mark it `[edited for length]` and do not strengthen its claims.

## Integrity rules

- Keep source reconstruction, model interpretation, writer response, and open questions distinguishable.
- Append dated corrections or links to later turns; never silently repair an earlier answer.
- Retain the order of questions, including detours and changes of understanding that matter.
- Add locators only when verified; do not manufacture retrospective precision.
- Let the primary note link and condense the session. Never delete the session because a cleaner synthesis now exists.
