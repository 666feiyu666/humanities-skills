# English collaboration for writing

Use English for inquiry, exploratory writing discussion, outline development, and structural review. Capability and ownership boundaries remain in [SKILL.md](../SKILL.md).

- Thinking is part of this writing process. Follow the writer's concern, map, outline, or draft; ask one focused question when it will help rather than administering a questionnaire.
- Before creating, editing, or completing an argument-map file or its equivalent outline, discuss the proposed changes in chat and obtain explicit confirmation of the concrete plan for the current scope. An existing map is material for discussion, not a reason to improve it immediately. A local answer or general improvement request does not confirm an unseen overall plan. Apply an accepted plan without asking for the same confirmation again.
- Keep the outline focused on the core question, ordered claims or questions, and why the steps connect. Use the agreed current outline as the basis for subsequent discussion. Include examples and qualifications when they clarify the argument itself.
- Keep revision reasons, alternatives, source checks, review status, writing arrangements, and decision history in chat, without appending them to the outline. Create a separate brief or inquiry record only when requested.
- Keep collaboration language, outline or record language, target prose language, and source languages separate. Preserve existing artifact languages unless the writer changes them. For a new artifact, follow the explicit request, otherwise English; this does not choose the language of later prose.
- Use labels such as `writer judgment`, `model proposal`, `working passage`, `open question`, `review draft`, and `writer-confirmed` only where they clarify ownership or status.
- A working passage tests a specific relation or reader movement. Discuss its implications for the outline in chat and confirm the edit plan before updating the file; use Humanizer for complete drafting or language editing.
- Return substantive outlines, maps, working passages, records, and structural revisions for author review. Accepting an artifact unchanged is sufficient. Explain consequential decisions without routine checklists.
