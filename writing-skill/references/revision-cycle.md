# Formal recursive revision cycle

## Applicability

Use this reference only for a systematic review, an explicitly multi-round revision, or a managed project that already uses formal version contracts. Do not impose it on an ordinary local rewrite, a single language polish, or a short continuation.

The cycle preserves one active revision scope while allowing later work to expose a higher-level problem. It prevents a language pass from quietly changing the argument and a structural pass from expanding into an unrequested rewrite.

## Observation layers

1. **Macro**: rhetorical situation, central claim, argument, audience, and arrangement.
2. **Relations**: section necessity, paragraph jobs, and relations among adjacent units.
3. **Language**: diction, reference, syntax, punctuation, rhythm, naturalness, and applicable voice preferences.

Choose the highest consequential unresolved layer unless the writer explicitly names the active layer. Diagnosing another layer does not authorize editing it in the current version.

## Classify findings in a formal cycle

Use localized equivalents of these category labels when they help preserve work across rounds:

- `[structure | macro]`: governing action, central claim, argument path, audience, section order, opening, or conclusion;
- `[structure | relations]`: section necessity, paragraph job, evidence-to-claim bridge, adjacent relation, or transition;
- `[language]`: diction, reference, syntax, punctuation, rhythm, repetition, naturalness, or applicable voice;
- `[source check]`: quotation, attribution, factual basis, concept, comparison, evidence, or scope for `reading-skill`;
- `[writer decision]`: a substantive position, scope, governing question, or overall argument choice reserved for the writer.

Statuses may be localized equivalents of:

- `[current round]`: authorized for the current version;
- `[deferred]`: preserve for a later version;
- `[return]`: stop at the writing boundary for reading, thinking, or a writer decision.

Do not require these labels outside a formal cycle.

## Set the version contract

Follow an existing project naming convention. If none exists and a name is useful, use a concise label in the project language such as `D00N-structural-revision` or `D00N-language-revision`. Use a mixed or purpose-specific label only when the writer authorizes that scope.

In a structure round, make the local wording changes needed to keep moved, split, merged, or newly connected prose grammatical. Defer broader polishing.

In a language round, preserve the central claim, section jobs, evidence roles, and argument path. If accurate wording requires changing one of them, return the issue to structure rather than concealing it with fluent prose.

Keep a deferred ledger only when findings must survive into later saved versions. Reclassify, retain with a reason, or close each item when the next relevant round begins.

## Run one revision loop

1. Diagnose the text's actual effect at the active layer.
2. Separate writing problems, source gaps, and substantive author decisions.
3. Confirm the version target and authorized scope.
4. Apply only the active changes and minimum dependent wording.
5. Re-read the affected whole and record consequential out-of-scope findings.
6. Choose one movement:
   - `stay` at the current layer;
   - `advance` to a more local layer;
   - `return` to a higher layer;
   - `return_to_invention` for an unchosen central question, claim, commitment, or overall path;
   - `return_to_reading` for a defined source or evidence check;
   - `exit` when the text satisfies the current publication purpose.

A completed language pass does not by itself prove that the article is finished.

## Use the layer references

### Macro

Read [rhetoric-review.md](rhetoric-review.md). Read [argument-audit.md](argument-audit.md) when claims, warrants, scope, objections, or conclusions need explicit audit.

Check the question promised by the opening, the claim established by the body, the job of each section, audience positioning, and whether the conclusion follows from the achieved path.

### Relations

Read [discourse-relations.md](discourse-relations.md). Check why each section or paragraph follows, each paragraph's nucleus, evidence and warrant relations, false cause, decorative contrast, hidden reorientation, excessive connective chaining, and ambiguous reference.

Repair the relation before replacing the connective. Return to macro only when repair would change the central claim, argument path, or scope.

### Language

Read [chinese-prose-quality.md](chinese-prose-quality.md) for Chinese target prose or [english-prose-quality.md](english-prose-quality.md) for English target prose. Read [reflective-public-essay-profile.md](reflective-public-essay-profile.md) only for Chinese prose when that profile applies.

Check exact diction, stable concepts, sentence subjects, reference, modifier and negation scope, punctuation, rhythm, repeated formulae, nominalization, over-neat closure, and preservation of the writer's recognizable voice.

Return to relations when no accurate local wording can express the supposed relation.

## Preserve boundaries

At every layer:

- preserve the writer's substantive ownership;
- preserve supplied names, titles, quotations, citations, page numbers, examples, and conceptual distinctions;
- distinguish writer claims, source claims, model proposals, and actual rhetorical effects;
- do not broaden a claim, erase uncertainty, or invent material;
- return an exact source need to `reading-skill`;
- return to `thinking-skill` only for an unchosen governing question, incompatible central claims, an overall argument path, or a substantive commitment.

Do not return to invention merely because a paragraph needs expansion or a local relation needs repair.

## Return the formal-cycle result

For review, return the active layer, realized structure or relation, strongest achieved effect, prioritized classified findings, author decisions, and next movement.

For authorized revision, return revised prose first, then a compact memo containing the version label, active layer, target, applied changes, deferred findings that must survive, movement, and unresolved boundaries.
