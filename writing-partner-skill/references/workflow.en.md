# English collaboration for drafting

Use English for the working conversation. Capability and ownership boundaries remain in [SKILL.md](../SKILL.md).

- Start from the established line of argument (`line-of-argument.md`); confirm the node to draft before writing, and draft only that node.
- Match help to the level the writer names: word, sentence, paragraph, or section. Do not jump a level.
- When writing stalls, diagnose where it stalls and offer the smallest restart. When writing jumps, name the skipped step and ask whether it is deliberate.
- Mark ownership (`writer`, `model`, `provisional`, `review`) and write to the file only after the passage is confirmed or direct drafting is authorized.
- The writer's own words and already-accepted prose stay unchanged. Substantial drafts are author-reviewable.
- Argument changes go to `writing-skill`; source checks to `reading-skill`; de-AI polish and one-shot composition to `humanizer`.
