# RWS Skills

这里存放我为 RWS 定制的技能（skill）。每个 skill 是一套可以单独调用的工作方式，陪我在阅读、思考、写作、口头表达的不同环节工作；它们彼此独立，我按当下的需要选用。

## 有哪些 skill

- **reading-skill**：理解、核查并记录来源。一起读一本书或一篇文章，弄清它说了什么，把阅读对话和卡片留下来。
- **writing-skill**：发展问题、论证和结构。通过讨论、思维图和试写，形成一个我可以审阅的提纲。
- **writing-partner-skill**：把已确立的论证线逐词、逐句、逐段、逐节写成正文；卡文或跳跃时陪我把话接下去。
- **review-suggestion-skill**：评价一篇写好的书评、随笔或论文，给出至多六条有优先级的修改建议。
- **speaking-skill**：把已经成立的内容改编成口头表达——演讲、讲稿、提词卡，并陪我排练。
- **meta-reflection-skill**：在阶段边界做元学习反思——理解发生了什么变化、现在能做什么、下一步往哪走；只在我想反思时用。
